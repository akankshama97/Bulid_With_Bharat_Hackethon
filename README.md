# BUILD With Bharat 4.0 — Invitation Email Template
A responsive HTML email invitation template for **BUILD With Bharat 4.0**, a National Level Hackathon organised by **CodeVerse × Voyager Coding Club**, KCC Institute of Technology and Management, Greater Noida — supported by Microsoft.

## 📌 Event Details
- **Dates:** 10–11 October 2026
- **Duration:** 24-Hour Hackathon
- **Venue:** KCC Institute of Technology & Management, Greater Noida
- **Team Size:** 2–5 Members
- **Eligibility:** B.Tech / BCA / MCA
- **Prize Pool:** ₹1,00,000 (₹50,000 / ₹30,000 / ₹20,000)

## 📁 What's in this repo
- `abc.html` — Table-based HTML email template (dark theme, mobile responsive), built for compatibility with major email clients (Outlook, Gmail, Apple Mail, etc.)

## ✨ Features
- Dark-themed, mobile-responsive layout using table-based structure for email client compatibility
- Tricolour accent bars 
- Event detail cards (date, duration, venue, team size, eligibility)
- Prize pool breakdown section
- CTA button linking to Unstop registration page
- Preheader text for inbox preview

## 🚀 Usage
1. Download/clone `abc.html`
2. Replace the banner image URL, registration link, and event details as needed
3. Paste the HTML into your email service provider (Mailchimp, SendGrid, etc.) as a custom HTML campaign
